# Project Title

Auths Platform

## Description

Auths Platform is a MERN stack application that provides authentication and authorization features. It allows users to register, log in, and manage their profiles securely.

## Features

- User registration and login
- JWT-based authentication
- Responsive design using Tailwind CSS
- Client-side routing with React Router
- Email notifications for user actions

## Installation

### Client

1. Navigate to the client directory:
   ```bash
   cd client
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

### Server

1. Navigate to the server directory:
   ```bash
   cd server
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   npm start
   ```

## Usage

After starting both the client and server, you can access the application at `http://localhost:3000`.
